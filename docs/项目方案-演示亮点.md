# 项目方案补充：演示亮点（精而不多）

> 定位：领导演示用「品质驾驶舱」试点。本轮只补 **3 个可复述亮点**，不扩模块、不造数。

## Slogan

**发现异常 → 锁定料号 → 闭环改善**

## 品质总览版面（领导视角）

总览自上而下：

1. **核心 KPI**：报废率、报废 PCS、投入、合格率、环比  
2. **动效图表**（趋势/仪表/TOP 料号与缺陷）  
3. **闭环条 + 决策卡**（页底：异常料号 → 已开/已关 8D + 未确认预警；决策卡可切换 TOP 料号）  

指标达成大看板、长篇决策简报、管理八宫格已从总览下线（数据仍在 API，详细页可看）。口径说明收进「📐 口径」按钮。

## 亮点一：异常料号一张卡

| 项 | 说明 |
|----|------|
| 目的 | 点 TOP 报废料号即可拍板：亏多少、主责工序、要不要开 8D |
| 数据 | ERP 报废/入库实据 + 缺陷/工序聚合；单价仅 `materials` 有价时估算，否则标「待定价」 |
| 入口 | 仪表板「异常料号决策卡」；点击 TOP 报废料号柱图 |
| 接口 | `GET /api/part_spotlight?part=&fiscal_period=` |
| 禁止 | 编造损失金额、编造主责工序、无入库时伪造报废率 |

## 亮点二：闭环状态条

| 项 | 说明 |
|----|------|
| 目的 | 证明不是只看板：当月异常料号 → 已开 8D → 已关闭 |
| 数据 | 当月有生产报废的 distinct 料号；8D 库中与这些料号关联的 open/closed |
| 展示 | 仪表板 KPI 上方一条状态条，可点进 8D / TOP 料号 |
| 字段 | `dashboard.closed_loop` |
| 禁止 | 用全库 8D 冒充「当月异常料号闭环」而不标注口径 |

## 亮点三：口径透明

| 项 | 说明 |
|----|------|
| 目的 | 领导问「这数怎么算的」可当场展开 |
| 展示 | 核心 KPI 旁「口径」按钮；展开公式与数据源 |
| 字段 | `dashboard.kpi_formulas` |
| 核心公式 | 报废率 = 报废 PCS / (报废 PCS + 入库 PCS)；无入库不计算率 |
