## 数据源映射

| 模块 | 数据来源 | 关键字段 |
|------|---------|---------|
| 精确查询 | MES工单 + ERP订单 | 生产日期、订单号、工单号、批次号 |
| MRB分析 | ERP-MRB评审单 | 报废缺陷、报废面积、责任工序 |

## 模块二：MRB数据分析

### 报废率计算公式
```
报废率 = 报废面积 / (报废面积 + 入库面积) × 100%
```

### 分析维度
1. **主要报废缺陷TOP10** - 柏拉图分布
2. **报废责任工序分析** - 工序责任占比饼图
3. **报废率趋势** - 按日期/周/月折线图
4. **报废率横向对比** - 各料号/产线对比

### 预期图表
- 缺陷柏拉图（80/20法则标识）
- 责任工序饼图
- 月度报废率趋势折线图
- 报废类型分布柱状图

## 模块三：MES生产数据

### 数据类型
| 类型 | 内容 | 数据源 |
|------|------|--------|
| 工序时间 | 各工序开始/结束时间、工序周期 | MES工单流转记录 |
| 设备信息 | 设备编号、设备名称、产能利用率 | MES设备台账 |
| 过程参数 | 速度、温度、压力、药水浓度等 | MES设备参数记录 |
| 药水异常 | 异常类型、发生时间、持续时长 | MES药水监控记录 |
| 过程检验 | 各工序检验良率、不良类型 | MES IPQC记录 |

### 预期图表
- 工艺流程甘特图（各工序时间可视化）
- 设备OEE仪表盘
- 关键参数趋势图（SPC控制图）
- 工序良率柱状图（按工序对比）

---

## 模块四：物料追溯

### 追溯链路
```
成品 → 半成品 → 原材料 → 供应商 → 来料批次 → IQC记录
```

### 追溯内容
- 原材料料号、规格、供应商
- 来料批次号、到货日期、IQC结论
- 投料记录（投料时间、投料量、操作员）
- 物料使用跟踪（使用工单、使用批次）

### 预期展示
- 物料追溯树状图
- 供应商来料质量统计
- 批次使用历史时间线

## 关键数据表结构

### MES侧
- `TBL_QM_INSPECT_RECORD` - 过程检验记录
- `TBL_WO_MES` - MES工单
- `TBL_ROUTE_RECORD` - 工序流转记录
- `TBL_EQUIPMENT_PARAMS` - 设备参数
- `TBL_CHEMICAL_LOG` - 药水监控

### ERP侧
- `P_WO` - ERP工单
- `E_JobMfgParts` - 料号信息
- `MRB_HEAD/MRB_ITEM` - MRB评审单
- `P_PP_BOM` - BOM物料清单
- `P_PP_Routing` - 工艺路线
